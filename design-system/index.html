One system · v1.2 · November 2026

Editorial restraint, app-grade structure, audit-grade data.

Warm paper and ink from barrettahern.com, structured with clear app patterns (4px grid, 28/36/44 controls, five status tones, page and layout primitives), accented in British racing green and extended with audit components. One palette, light and dark.

Principles

1. Tokens, never hex

Components read CSS variables. A palette is a token set, not a restyle.

2. One accent per view

The accent marks the single thing the page argues from. Status uses the five status tones, never the accent.

3. Colour never carries meaning alone

Every status has a word and a marker. Every delta has an arrow and a comparison period.

4. Every number has a source

Client, period, source. Label anything modelled or illustrative. Never invent figures.

5. Reuse before you build

If a component exists here, copy it. New patterns use the same tokens and get added to this gallery.

6. Quiet motion, real focus

200ms ease-out, honours reduced motion. A visible 2px focus ring on every interactive element.

Tokens

Live values for the current theme. Click a swatch to copy its variable.

One palette. Paper neutrals carry the page. British racing green (--accent) is the single accent. Cotswold stone (--accent-2) is the quiet secondary for stats and trends. The accent is lighter on dark surfaces so contrast holds; use the tokens and it flips for you.
